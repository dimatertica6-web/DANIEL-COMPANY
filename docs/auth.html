Auth Module

Overview

Authentication and authorization system with password management, JWT tokens, and session handling.

Features

  • Password hashing (PBKDF2)
  • JWT token generation and validation
  • Session management
  • User management
  • Role-based access control
  • Password validation

Usage

from auth.engine import AuthEngine

auth = AuthEngine()
auth.initialize()
auth.create_user("admin", "SecurePass123!", "admin")
token = auth.authenticate("admin", "SecurePass123!")
