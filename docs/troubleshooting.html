Troubleshooting

Common Issues

ModuleNotFoundError

pip install -r requirements.txt

Connection refused

Check your network connection or firewall settings.

SSL Certificate Error

python -c "import ssl; ssl._create_default_https_context = ssl._create_unverified_context"

GUI not starting

Ensure PyQt6 is installed: pip install PyQt6

Scan timeout

Increase timeout in config: timeout: 60

Permission denied

Run with sudo/administrator privileges.
