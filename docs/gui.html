GUI Interface

Overview

Modern PyQt6 graphical interface with custom SVG icons and minimal design.

Features

  • Dark/light theme support
  • Custom SVG icons
  • Real-time progress bars
  • Interactive dashboards
  • Scan results visualization
  • Export buttons

Launch

python gui.py

Screens

  • Dashboard – Overview
  • Scan – Configure and run scans
  • Exploits – Select and run exploits
  • Results – View scan results
  • Settings – Configure application
