Configuration

Config Files

GlanderIO uses YAML/JSON configuration files:

config.yaml                # Main configuration
proxy.yaml                 # Proxy settings
logger.yaml                # Logging configuration
database.yaml              # Database settings

Main Config Example

project:
  name: GlanderIO
  version: 3.0.0

core:
  mode: production
  debug: false
  max_workers: 100
  timeout: 300

modules:
  enabled:
    scanner: true
    exploits: true
    telemetry: true

Environment Variables

Variable Description
GLANDER_DEBUG Enable debug mode
GLANDER_LOG_LEVEL Log level (DEBUG/INFO/WARNING/ERROR)
GLANDER_OUTPUT_DIR Output directory

CLI Overrides

python run.py --config custom.yaml --debug
