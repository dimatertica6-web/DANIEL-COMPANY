Metadata Module

Overview

Metadata extraction, cleaning, and analysis from various file types.

Features

  • EXIF extraction from images
  • File metadata (size, creation, modification)
  • HTML metadata (OG tags, Twitter cards, schema)
  • Sensitive data redaction
  • Metadata cleaning and sanitization

Usage

from metadata.engine import MetadataEngine

meta = MetadataEngine()
result = meta.extract_from_file("image.jpg")
cleaned = meta.clean_sensitive(result)
