Installation Steps

1

Clone Repository

git clone https://github.com/yourusername/eraser.git
cd eraser
2

Install Dependencies

sudo apt-get update
sudo apt-get install -y build-essential g++ make cmake \
    libssl-dev libcurl4-openssl-dev libpcap-dev \
    libsqlite3-dev libjsoncpp-dev libtinyxml2-dev \
    libyaml-cpp-dev libboost-all-dev libgpgme-dev \
    libargon2-dev libscrypt-dev libxml2-dev libxslt1-dev \
    uuid-dev libsystemd-dev libudev-dev zlib1g-dev \
    libpq-dev libmysqlclient-dev libmariadb-dev \
    libsndfile1-dev libasound2-dev
3

Compile Project

make clean
make
4

Run ERASER

./eraser
# For root privileges (recommended)
sudo ./eraser

First Run Guide

Quick Tip: After launching, you'll see a menu with 200+ functions. Enter the function number and press Enter to execute.
Pro Tip: Use sudo ./eraser for full functionality (network scanning, MAC changing, etc.)
