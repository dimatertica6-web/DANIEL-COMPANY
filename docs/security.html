Best Practices

1. Use Virtual Environment

Always run ERASER in an isolated environment (VM, container, or dedicated machine)

# Docker example
docker run -it --rm eraservm:latest

2. Enable Anonymity Features

Use Tor, VPN, and proxy chains for anonymous operations

# Enable Tor
./eraser -> 53 (enableTor)

# Enable VPN
./eraser -> 54 (enableVPN)

3. Regular Updates

Keep the framework and dependencies updated

git pull
make clean
make

4. Secure Configuration

Use strong passwords and encryption keys

# Generate secure key
./eraser -> 48 (generateKey)

5. Log and Monitor

Enable logging and monitoring for security auditing

# Enable logging
export ERASER_LOG=1
./eraser 2>&1 | tee eraser.log

Threat Model

Network Threats

  • MITM attacks - mitigated by TLS/SSL
  • Packet sniffing - mitigated by encryption
  • Traffic analysis - mitigated by Tor/VPN

System Threats

  • Privilege escalation - mitigated by sandboxing
  • Memory attacks - mitigated by ASLR/DEP
  • File system attacks - mitigated by encryption

Application Threats

  • Code injection - mitigated by input validation
  • Buffer overflow - mitigated by security checks
  • Race conditions - mitigated by synchronization
