Installation

System Requirements

Requirement Minimum
Python 3.9+
RAM 4 GB
Storage 2 GB
OS Windows/Linux/macOS

Quick Install

# Clone repository
git clone https://github.com/yourusername/glanderio.git
cd glanderio

# Install dependencies
pip install -r requirements.txt

# Verify installation
python -c "import core; print('OK')"

Installation Options

1. Full Installation

python installer.py --full

2. Minimal Installation

python installer.py --minimal

3. Development Installation

pip install -e .

Dependencies

Main dependencies: requests, beautifulsoup4, cryptography, flask, pyqt6, sqlalchemy

Verify Installation

python run.py --help
Note: For GUI support, ensure PyQt6 is properly installed.
