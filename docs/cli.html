CLI Commands

run.py

Option Description
-u, --url Target URL
-o, --output Output directory
-f, --format Output format (json/csv/html)
-v, --verbose Verbose output
-t, --threads Number of threads
--timeout Request timeout
--proxy Proxy URL
--tor Use TOR

exploits.py

Option Description
-u, --url Target URL
-m, --module Exploit module (xss,sqli,rce,lfi,rfi,csrf,ssrf,xxe)
-p, --payload Custom payload
--list List all modules

installer.py

Option Description
-i, --install Install package
-u, --uninstall Uninstall package
-l, --list List installed packages
--update Update package

telemetry.py

Option Description
--start Start server
--stop Stop server
--status Server status
--port Custom port
