Database Module

Overview

Database abstraction layer with support for SQLite, MySQL, and PostgreSQL.

Features

  • SQLite, MySQL, PostgreSQL support
  • Query optimization
  • Connection pooling
  • Migration management
  • Backup and restore
  • Performance analysis

Usage

from database.engine import DatabaseEngine

db = DatabaseEngine()
db.connect("sqlite:///glander.db")
db.execute("SELECT * FROM scans")
