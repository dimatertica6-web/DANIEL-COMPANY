FAQ

What is GlanderIO?

GlanderIO is a modular security framework for penetration testing and reconnaissance.

Is GlanderIO free?

Yes, GlanderIO is open-source and free to use under the MIT license.

What platforms are supported?

Windows, Linux, and macOS are supported.

Do I need Python experience?

Basic Python knowledge is helpful but not required for basic usage.

Can I use it on any website?

Only on websites you own or have explicit permission to test.

How do I report a bug?

Open an issue on GitHub with detailed steps to reproduce.
