❓ Frequently Asked Questions

Answers to the most common questions about ERASER

What is ERASER?

ERASER is a comprehensive cyber security framework that combines 200+ modules for anonymity, cryptography, scanning, exploitation, networking, forensics, and optimization in one tool.

How do I install ERASER?

Clone the repository, install dependencies, and compile:

git clone https://github.com/yourusername/eraser.git
cd eraser
make clean
make
./eraser
What are the system requirements?

Minimum: Kali Linux/Ubuntu 22.04, 4GB RAM, 10GB storage, 2 cores. Recommended: Kali Linux 2026+, 16GB RAM, 50GB SSD, 8 cores.

Is ERASER free to use?

Yes! ERASER is completely free and open-source under the MIT License. You can use, modify, and distribute it freely.

How do I enable anonymity features?

Use the menu options: 51 (rotateUserAgent), 52 (rotateProxy), 53 (enableTor), 54 (enableVPN), 55 (enableStealth).

Can I use ERASER on Windows?

ERASER is designed for Linux, but works on Windows via WSL2 (Windows Subsystem for Linux) with Kali or Ubuntu.

How do I update ERASER?

Pull the latest changes and recompile:

git pull
make clean
make
What cryptographic algorithms are supported?

AES-256, RSA-4096, SHA-256, GPG, JWT, SSL/TLS, MD5, Base64, XOR, and post-quantum algorithms.

How do I create a backdoor?

Use option 108 (backdoor create) and enter LHOST and LPORT. The backdoor will be created as backdoor.exe.

Is ERASER legal to use?

ERASER is legal for educational purposes and authorized penetration testing. Unauthorized use is prohibited by law.

How do I report a bug?

Create an Issue on GitHub with detailed description, steps to reproduce, and system information.

Can I contribute to ERASER?

Yes! Fork the repository, create a branch, make your changes, and submit a Pull Request. All contributions are welcome.

How do I clear logs and history?

Use option 55 (clear logs), 80 (clear logs), or 81 (history -c). Also option 78 (stealth) enables full stealth mode.

What is the difference between Tor and VPN?

Tor routes through multiple nodes for anonymity but is slower. VPN encrypts all traffic and is faster. Both can be used together.

How do I restore a backup?

Use option 119 (file recover) for file recovery, or the backup module if you created backups with the system.

Is there a GUI version?

Currently ERASER is CLI-based only. A web GUI is planned for version 13.0.
