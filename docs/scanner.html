Scanner Module

Overview

Full-site scanning engine with technology detection, vulnerability assessment, and data extraction.

Features

  • DNS lookup and WHOIS
  • robots.txt parsing
  • Sitemap extraction
  • SSL/TLS information
  • Technology detection (CMS, frameworks, servers)
  • Subdomain enumeration
  • Port scanning
  • Cookie gathering
  • Full site crawling
  • Hidden directory discovery
  • Sensitive file detection
  • Backup file scanning
  • Admin panel discovery
  • API endpoint discovery
  • GraphQL endpoint detection
  • CMS enumeration
  • Email extraction
  • Security header analysis

Usage

from run import GlanderMain

scanner = GlanderMain("https://target.com")
results = scanner.run()

# Access results
print(results["total_pages"])
print(results["technologies"])
print(results["subdomains"])

Configuration

# config.yaml
scanner:
  max_pages: 1000
  max_threads: 50
  timeout: 30
  deep_scan: true
