Usage

Basic Commands

# Interactive menu
python menu.py

# Full scan
python run.py -u https://target.com

# Exploit scan
python exploits.py -u https://target.com -m xss,sqli

# Telemetry server
python -m telemetry.engine --start

# Local storage
python -m local_storage.engine --start

# GUI
python gui.py

Scan Modes

Mode Command
Quick Scan python run.py -u https://target.com --quick
Full Scan python run.py -u https://target.com
Deep Scan python run.py -u https://target.com --deep
Stealth Mode python run.py -u https://target.com --stealth

Output Formats

python run.py -u https://target.com -o report.json --format json
python run.py -u https://target.com -o report.csv --format csv
python run.py -u https://target.com -o report.html --format html
