Proxy Module

Overview

Proxy management with support for HTTP, HTTPS, SOCKS4, SOCKS5, and TOR.

Features

  • Proxy pool management
  • Proxy rotation
  • Proxy validation
  • Geolocation support
  • Anonymity classification
  • Proxy chain building

Usage

from proxy.engine import ProxyEngine

proxy = ProxyEngine()
proxy.add("192.168.1.1", 8080)
best = proxy.get_best()
print(best.host, best.port)
