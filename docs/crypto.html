🔐 Crypto Module

Advanced cryptography and encryption toolkit

Overview

The Crypto module provides state-of-the-art encryption, hashing, and cryptographic utilities.

Encryption Algorithms

Algorithm Strength Use Case
AES-256 256-bit File encryption, data protection
RSA-4096 4096-bit Asymmetric encryption, key exchange
SHA-256 256-bit Hash generation, integrity checks
GPG Multiple Email encryption, signing
JWT 256-bit Authentication tokens

Usage Examples

AES Encryption

# Encrypt file
./eraser -> 46
# Enter file path: secret.txt
# Enter key: [encryption key]
# File encrypted successfully

RSA Key Generation

# Generate RSA keys
./eraser -> 75
# RSA keys generated:
# private.pem
# public.pem

Hash Generation

# Generate SHA-256 hash
./eraser -> 41
# Enter text: hello
# SHA-256: 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
