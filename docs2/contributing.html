Contributing

How to contribute to RERONRF BOT.

Guidelines

  • Follow PEP 8 style guide
  • Write tests for new features
  • Update documentation
  • Keep modules independent
  • No external API dependencies

Adding a New Module

mkdir new_module
touch new_module/__init__.py
touch new_module/main.py
touch new_module/engine.py

Update main.py imports:

from new_module import *

Adding a New Command

Add to handlers/command_handlers.py:

@bot.message_handler(commands=['newcmd'])
def new_cmd(message):
    bot.reply_to(message, "New command executed")

Testing

python -m pytest tests/
python scripts/test.py

Pull Request Process

  1. Fork the repository
  2. Create a feature branch
  3. Make your changes
  4. Run tests
  5. Submit PR
