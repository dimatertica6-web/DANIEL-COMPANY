API Reference

REST API endpoints for RERONRF BOT.

Base URL

http://localhost:8000/api/v1

Authentication

Most endpoints require authentication via Bearer token:

Authorization: Bearer your_token_here

Endpoints

GET/health

Health check endpoint.

{"status":"healthy","version":"8.0.0","timestamp":"2026-01-15T10:00:00"}
GET/users

Get all users.

GET/users/{id}

Get user by ID.

POST/users

Create a new user.

GET/scans

Get all scans.

POST/scans

Start a new scan.

GET/attacks

Get all attacks.

POST/attacks

Start an attack.

GET/reports

Get all reports.

GET/system/info

Get system information.

GET/system/status

Get system status.

GET/demo/all

Get all demo data.

GET/routes

Get all available routes.

Error Responses

{"status":404,"success":false,"message":"Not Found","data":null,"timestamp":"2026-01-15T10:00:00"}

Rate Limiting

API requests are limited to 60 requests per minute per IP.
