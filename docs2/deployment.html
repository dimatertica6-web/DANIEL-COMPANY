Deployment

Deploy RERONRF BOT to production.

VPS Deployment

Recommended for 24/7 operation.

sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip git -y
git clone https://github.com/yourusername/RERONRF_BOT.git
cd RERONRF_BOT
pip install -r requirements.txt

Systemd Service

Create a systemd service for auto-restart.

sudo nano /etc/systemd/system/reronrf.service
[Unit]
Description=RERONRF BOT
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/RERONRF_BOT
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable reronrf
sudo systemctl start reronrf

Supervisor Deployment

sudo apt install supervisor -y
sudo nano /etc/supervisor/conf.d/reronrf.conf
[program:reronrf]
command=python3 /path/to/RERONRF_BOT/bot.py
directory=/path/to/RERONRF_BOT
user=root
autostart=true
autorestart=true
stdout_logfile=/path/to/RERONRF_BOT/logs/bot.log
stderr_logfile=/path/to/RERONRF_BOT/logs/error.log
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start reronrf

Docker Deployment

docker build -t reronrf .
docker run -d --name reronrf --restart always reronrf

Screen Deployment

screen -S reronrf
cd /path/to/RERONRF_BOT
python bot.py
# Ctrl+A, D to detach

Nohup Deployment

nohup python bot.py > logs/bot.log 2>&1 &

Heroku Deployment

heroku create reronrf-bot
heroku config:set BOT_TOKEN=your_token
heroku config:set ADMIN_ID=your_id
git push heroku main

Monitoring

  • systemctl status reronrf — Check service status
  • supervisorctl status reronrf — Check supervisor status
  • docker logs reronrf — View Docker logs
  • tail -f logs/bot.log — View bot logs
