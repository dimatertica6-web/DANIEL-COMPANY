Troubleshooting

Common issues and their solutions.

Bot Won't Start

  • Check .env file exists with BOT_TOKEN
  • Verify Python version: python --version
  • Install dependencies: pip install -r requirements.txt
  • Check logs: tail -f logs/errors.log

Module Import Errors

  • Check module exists in project structure
  • Verify __init__.py exists in module folder
  • Check for circular imports
  • Add sys.path.insert(0, os.getcwd()) in main.py

Database Errors

  • Check data.db exists
  • Verify write permissions
  • Run migrations: python scripts/migrate.py
  • Check database logs: tail -f logs/database.log

Telegram API Errors

  • Verify bot token is valid
  • Check internet connection
  • Ensure bot is not blocked
  • Check rate limits

Common Fixes

# Reinstall dependencies
pip install -r requirements.txt --upgrade

# Reset database
rm data.db
python scripts/init.py

# Clear cache
rm -rf cache/*

# Restart bot
systemctl restart reronrf
