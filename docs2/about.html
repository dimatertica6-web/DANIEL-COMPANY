About

RERONRF BOT — Ultimate Security Toolkit.

Project Overview

RERONRF BOT is a comprehensive Telegram bot built for security research, OSINT investigations, and penetration testing. It includes 43 modules with over 90 commands, all without requiring external API keys.

Features

  • Full OSINT toolkit
  • Security scanning
  • Attack simulation
  • Analytics and monitoring
  • Data management
  • Encryption and security
  • Multi-language support
  • Modular architecture

Tech Stack

  • Python 3.10+
  • pyTelegramBotAPI
  • SQLite / Redis / MongoDB
  • REST API
  • WebSocket
  • gRPC
  • HTML / CSS / JS
