Configuration

Configure RERONRF BOT for your environment.

Environment Variables

# Telegram
BOT_TOKEN=your_bot_token
ADMIN_ID=your_telegram_id

# Debug
DEBUG=False
LOG_LEVEL=INFO

# Limits
MAX_THREADS=150
DEFAULT_DDOS_THREADS=50
DEFAULT_DDOS_DURATION=30
RATE_LIMIT_CALLS=20
RATE_LIMIT_PERIOD=60

# Database
DB_PATH=data.db
REDIS_URL=redis://localhost:6379/0
MONGO_URI=mongodb://localhost:27017/

# Cache
CACHE_TTL=300

# API
API_TIMEOUT=10
USER_AGENT_ROTATE=True
PROXY_ENABLED=False
PROXY_URL=socks5://127.0.0.1:9050

Config Files

Additional configuration files in config/:

  • settings.py — Main settings
  • constants.py — Constants
  • database.py — Database settings
  • logging.py — Logging settings
  • security.py — Security settings
  • rate_limit.py — Rate limit settings
  • cache.py — Cache settings
  • api.py — API settings
  • bot.py — Bot settings
  • webhook.py — Webhook settings

Data Files

JSON data files in data/:

  • users.json — Users data
  • scans.json — Scans data
  • attacks.json — Attacks data
  • reports.json — Reports data
  • history.json — History data
  • settings.json — Settings data
  • config.json — Config data

Customization

Modify config/settings.py to customize:

  • Bot name and version
  • Default limits
  • Feature flags
  • Logging levels
  • API endpoints
