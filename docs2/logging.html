Logging

Comprehensive logging system for monitoring.

Log Files

Located in logs/ directory:

  • bot.log — Main bot logs
  • errors.log — Error logs
  • access.log — Access logs
  • commands.log — Command logs
  • modules.log — Module logs
  • api.log — API logs
  • database.log — Database logs
  • attacks.log — Attack logs
  • scans.log — Scan logs
  • osint.log — OSINT logs

Log Levels

  • DEBUG — Detailed debugging information
  • INFO — General information
  • WARNING — Warning messages
  • ERROR — Error messages
  • CRITICAL — Critical errors

Viewing Logs

tail -f logs/bot.log
tail -f logs/errors.log
tail -f logs/access.log

Log Rotation

Logs are automatically rotated. Configure in config/logging.py:

LOGGING_CONFIG = {
    'handlers': {
        'file': {
            'class': 'logging.handlers.RotatingFileHandler',
            'maxBytes': 10485760,
            'backupCount': 5
        }
    }
}
