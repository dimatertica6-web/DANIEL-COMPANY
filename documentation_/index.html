Core

Heart of the framework — engine, crypto, network, c2, exploits, persistence, and more.
engine
core/engine.py
The main orchestration layer. Initializes all subsystems, manages the attack lifecycle, dispatches tasks to threads, and coordinates between C2, network, and persistence modules. Provides a unified API for the entire framework.
crypto
core/crypto.py
Symmetric (AES-GCM) and asymmetric (RSA-OAEP) encryption, secure key derivation (PBKDF2), hashing (SHA-256/512), and random number generation. Used for C2 traffic, configuration encryption, and payload obfuscation.
c2
core/c2.py
Command & Control server supporting 38 built-in commands. Handles client authentication, command queuing, job scheduling, and real-time status reporting. Implements a custom protocol over TCP/TLS with built-in heartbeat and keep-alive.
persistence
core/persistence.py
Unified interface for Windows (Registry, Services, Scheduled Tasks), Linux (cron, systemd, rc.local, LD_PRELOAD), and macOS (launchd, StartupItems). Provides install, remove, and check methods with stealth options.
exploits
core/exploits.py
Registry and loader for 28 exploits including Log4j (CVE-2021-44228), Spring4Shell (CVE-2022-22965), Struts2, and WebLogic. Each exploit is dynamically loaded and executed against a target with configurable payloads.
network
core/network.py
Low-level networking: raw socket creation, packet crafting (IP/TCP/UDP/ICMP), checksum calculation, spoofing, and interface management. Supports both IPv4 and IPv6 with full control over headers and options.
