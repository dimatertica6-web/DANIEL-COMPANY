Stealth

Anti-debug, anti-VM, process hiding, log cleaner, sandbox detection.
anti_debug
stealth/anti_debug.py
Detects debugging tools (gdb, windbg, x64dbg) using ptrace, /proc/self/status, and PEB flags. Can exit, crash, or obfuscate execution. Implements multiple anti-debugging techniques including timing attacks and software breakpoint detection.
anti_vm
stealth/anti_vm.py
Detects virtualized environments (VMware, VirtualBox, QEMU, Hyper-V) using hardware instructions, network adapter checks, and process enumeration. Can halt execution or change behavior in virtualized environments.
process_hider
stealth/process_hider.py
Hides process from ps, tasklist, and process viewers using kernel-level techniques. Also modifies process names and parent PIDs. Implements DKOM (Direct Kernel Object Manipulation) for process hiding on Windows.
sandbox_detector
stealth/sandbox_detector.py
Detects virtualized environments (VMware, VirtualBox, QEMU, Hyper-V) using hardware, network, and timing analysis. Can halt or redirect execution. Implements sandbox escape detection and analysis environment fingerprinting.
log_cleaner
stealth/log_cleaner.py
Cleans system logs (Windows Event Log, Linux syslog, auth.log) and application logs. Can selectively remove entries based on timestamps or patterns. Implements log tampering and evidence destruction techniques.
