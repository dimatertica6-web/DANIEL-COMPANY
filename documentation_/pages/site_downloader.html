Site Downloader

Full site mirroring, asset download, HTML processing, and WordPress scanning.
downloader
site_downloader/downloader.py
Downloads complete websites including HTML, CSS, JS, images, and fonts. Reconstructs directory structure and rewrites links for offline viewing. Supports parallel downloads, resume capability, and proxy integration.
site_mirror
site_downloader/site_mirror.py
Advanced mirroring with recursive crawling, depth control, and domain restriction. Handles cookies, sessions, and basic authentication. Implements intelligent asset detection and can generate offline-compatible websites with relative paths.
asset_downloader
site_downloader/asset_downloader.py
Specialized downloader for site assets: images, CSS, JavaScript, fonts, and media files. Supports concurrent downloads, retry logic, and bandwidth throttling. Can detect and download assets from responsive designs.
html_processor
site_downloader/html_processor.py
Processes and sanitizes HTML content: rewrites links, inlines assets, and optimizes for offline viewing. Removes tracking scripts and unnecessary external dependencies. Can convert dynamic content to static HTML.
