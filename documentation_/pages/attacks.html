Attacks 42 modes

Layer 3/4/7 flood attacks, amplification, and protocol abuse.
http_flood
attacks/http_flood.py
HTTP/1.1 and HTTP/2 GET/POST flood with randomized headers, User-Agents, and query parameters. Supports keep-alive, pipelining, and proxy rotation. Can target specific paths and use cookies.
udp_flood
attacks/udp_flood.py
High-volume UDP flood with spoofed source IP and port. Can target specific ports with custom payloads. Works over IPv4 and IPv6 with configurable packet size and rate limiting.
syn_flood
attacks/syn_flood.py
Classic TCP SYN flood with fully spoofed IPs. Uses raw sockets to send SYN packets with random source ports and sequence numbers. Bypasses SYN cookies with randomized timestamps.
icmp_flood
attacks/icmp_flood.py
ICMP echo request (ping) flood with spoofed source addresses. Can use fragmented packets and custom payload sizes. Effective against misconfigured networks.
dns_amp
attacks/dns_amp.py
DNS amplification using ANY/CH/TXT queries with spoofed source. Leverages open resolvers to amplify traffic by a factor of 50-100x. Includes list of public resolvers.
slowloris
attacks/slowloris.py
Slowloris attack keeping many connections open with partial HTTP headers. Uses randomized intervals, connection pooling, and proxy chaining to exhaust server resources.
ntp_amp
attacks/ntp_amp.py
NTP monlist amplification with pre-fetched list of vulnerable servers. Achieves amplification factors of 200-500x. Uses spoofed UDP packets with randomized transaction IDs.
ssdp_amp
attacks/ssdp_amp.py
SSDP reflection using UPnP discovery requests. Exploits misconfigured devices to amplify traffic up to 30x. Supports both IPv4 and IPv6.
