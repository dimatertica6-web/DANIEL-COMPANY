P2P

Decentralized peer discovery, DHT, consensus, message routing.
dht_node
p2p/dht_node.py
Distributed hash table implementation for decentralized peer storage. Uses Kademlia algorithm with XOR distance metrics. Supports peer discovery and routing with robust node churn handling.
peer_discovery
p2p/peer_discovery.py
Bootstrap and discovery of peers using DNS seeds, hardcoded nodes, and UDP broadcast. Maintains a peer list with health checks and liveness probes. Implements peer validation and reputation scoring.
consensus
p2p/consensus.py
Simple consensus protocol (Raft-inspired) for coordinating actions across the peer network. Ensures agreement on command sequence and state changes. Implements leader election and log replication with fault tolerance.
message_routing
p2p/message_routing.py
Peer-to-peer message routing with support for broadcast, multicast, and unicast messages. Implements message queuing, prioritization, and delivery guarantees with optional encryption.
