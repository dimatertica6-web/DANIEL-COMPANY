Full Scan

Comprehensive site & network scanner with report generation.
scanner
full_scan/scanner.py
All-in-one scanner that combines port scanning, subdomain enumeration, DNS reconnaissance, and technology fingerprinting. Provides a unified output with severity classification and risk scoring. Supports both single-target and batch scanning modes.
report_generator
full_scan/report_generator.py
Generates professional HTML, PDF, and JSON reports with visual charts, vulnerability summaries, and recommendations. Includes interactive dashboards for analysis with filtering and sorting capabilities. Supports export to multiple formats.
