Parser

HTML, JSON, XML, CSV, log, regex, and data extraction parsers.
html_parser
parser/html_parser.py
Fast HTML parsing with BeautifulSoup and lxml. Extracts links, forms, metadata, and DOM elements. Implements fault-tolerant parsing with automatic encoding detection and malformed HTML correction.
json_parser
parser/json_parser.py
JSON parsing and manipulation with schema validation. Handles JSON lines and streaming. Implements deep JSON traversal, path-based extraction, and automatic type conversion with validation against JSON schemas.
log_parser
parser/log_parser.py
Parses Apache, Nginx, Syslog, and custom log formats. Extracts timestamps, IPs, and status codes. Implements pattern-based log parsing, field extraction, and log normalization with support for multiple log formats.
xml_parser
parser/xml_parser.py
XML parsing with XPath and XQuery support. Handles namespaces and large XML documents with streaming. Implements XML validation against DTD and XSD schemas with automatic namespace resolution.
