WordPress Scanner

WordPress plugin, theme, user, and vulnerability scanner.
plugin_scanner
wordpress_scanner/plugin_scanner.py
Enumerates installed plugins via common paths, /wp-content/plugins/, and readme.txt. Detects outdated versions and known vulnerabilities. Uses a database of over 50,000 plugins with version detection and CVE mapping.
vuln_scanner
wordpress_scanner/vuln_scanner.py
Scans for WordPress core vulnerabilities, plugin exploits, and theme issues. Uses a local vulnerability database with CVE references and detailed exploitation information. Provides remediation steps and patch recommendations.
theme_scanner
wordpress_scanner/theme_scanner.py
Detects installed themes and their versions. Scans for vulnerable theme files, header injections, and malicious code. Uses both signature-based and heuristic analysis for comprehensive theme security assessment.
user_scanner
wordpress_scanner/user_scanner.py
Enumerates WordPress users via REST API, author archives, and comment sections. Can perform username validation and password bruteforce attacks. Implements rate limiting detection and bypass techniques.
