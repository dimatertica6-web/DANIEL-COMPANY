Monitoring

System, process, network, file, and registry monitoring with alerts.
system_monitor
monitoring/system_monitor.py
Real-time system monitoring: CPU, memory, disk, network stats. Generates alerts on thresholds and logs historical data. Implements trend analysis and anomaly detection for early warning of performance issues.
process_monitor
monitoring/process_monitor.py
Tracks running processes, detects suspicious behavior, and logs process creation/termination. Can kill and restart processes. Implements process tree analysis and resource usage tracking with automated remediation.
network_monitor
monitoring/network_monitor.py
Captures and analyzes network traffic for anomalies, DDoS patterns, and malicious payloads. Uses pcap with BPF filters. Implements real-time packet analysis, protocol detection, and bandwidth usage tracking with automatic alerting.
log_monitor
monitoring/log_monitor.py
Monitors system and application logs for security events and errors. Supports tailing, pattern matching, and event correlation. Can trigger actions based on log patterns and integrate with SIEM systems.
