Anti-Forensics

Disk wiping, file shredding, log wiping, metadata removal, timestomping.
disk_wiper
anti_forensics/disk_wiper.py
Overwrites free disk space with random data patterns (DoD, Gutmann, zeroes) to prevent recovery of deleted files. Supports multiple passes and verification. Can wipe entire partitions with secure erase commands.
file_shredder
anti_forensics/file_shredder.py
Securely deletes files by overwriting with random data multiple times, then renaming and truncating. Prevents file carving and forensic recovery. Implements multiple shredding patterns including DoD 5220.22-M and Gutmann.
log_wiper
anti_forensics/log_wiper.py
Clears system logs (Windows Event Log, Linux syslog, auth.log) and application logs. Can selectively remove entries based on timestamps or patterns. Implements event log clearing with audit policy bypass.
timestomper
anti_forensics/timestomper.py
Modifies file timestamps (MAC timestamps) to decouple activity from actual times. Can set timestamps to arbitrary dates or copy from other files. Implements timestomping for directories and files in bulk.
metadata_remover
anti_forensics/metadata_remover.py
Removes metadata from files including EXIF data, document properties, and file system extended attributes. Supports batch processing for common file types (images, documents, archives).
