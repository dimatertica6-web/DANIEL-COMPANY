Anonymity

IP rotation, MAC spoofing, VPN/Tor integration, proxy chaining, and fingerprint obfuscation.
ip_rotator
anonymity/ip_rotator.py
Rotates IP addresses via proxy lists, VPN APIs, or Tor circuit switching. Supports geo-diverse IP pools and automatic failover. Implements IP rotation schedules, proxy health checks, and automatic bypass of IP-based rate limiting.
tor_manager
anonymity/tor_manager.py
Integrates with Tor SOCKS proxy and manages circuit creation/termination. Supports stream isolation and hidden services. Implements Tor circuit management, identity renewal, and automatic proxy configuration.
proxy_rotator
anonymity/proxy_rotator.py
Manages proxy rotation across multiple proxy types (HTTP, HTTPS, SOCKS4, SOCKS5). Supports proxy authentication, geolocation filtering, and performance-based selection. Implements proxy chaining and cascading for increased anonymity.
vpn_manager
anonymity/vpn_manager.py
Manages VPN connections with support for multiple providers. Handles connection establishment, kill switch, and DNS leak protection. Implements automated VPN rotation and region switching based on configurable rules.
