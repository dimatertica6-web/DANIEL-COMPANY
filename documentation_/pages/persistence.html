Persistence

Windows Registry, Services, Tasks; Linux crontab, systemd; macOS launchd.
windows_registry
persistence/windows_registry.py
Installs persistence via Run, RunOnce, and Startup folders. Also supports COM hijacking and scheduled tasks with trigger conditions. Implements multiple evasion techniques including registry redirection and alternative data streams.
windows_service
persistence/windows_service.py
Creates Windows services with configurable startup types (automatic, manual, delayed). Supports service recovery options and can impersonate legitimate system services. Implements service DLL hijacking and path interception.
linux_cron
persistence/linux_cron.py
Adds cron jobs for root or user with randomized intervals. Supports @reboot, hourly, daily, and custom schedules. Implements cron.d and crontab injection with log suppression.
linux_systemd
persistence/linux_systemd.py
Creates systemd service units with various types (simple, forking, oneshot). Supports start limits, restart policies, and environment variables. Can also create timer units for scheduled execution.
macos_launchd
persistence/macos_launchd.py
Creates LaunchDaemon or LaunchAgent plist files with auto-restart and keep-alive. Supports root and user-level installations. Implements start intervals, network availability triggers, and system event triggers.
