Site Crawler

Recursive crawling, link extraction, meta extraction, and sitemap generation.
crawler
site_crawler/crawler.py
Recursive web crawler with configurable depth, parallelization, and politeness. Extracts all URLs, forms, and navigation structures. Implements robots.txt parsing and respects crawl delays. Supports breadth-first and depth-first traversal strategies.
link_extractor
site_crawler/link_extractor.py
Intelligent link extraction from HTML and JavaScript. Extracts href, src, data-*, and custom attributes. Detects and handles dynamic links loaded via AJAX and JavaScript rendering. Supports extraction from SPA frameworks.
sitemap_generator
site_crawler/sitemap_generator.py
Generates XML sitemap with priority, change frequency, and last modification dates. Can also create HTML sitemap for user navigation. Supports large sites with automatic pagination and compression.
meta_extractor
site_crawler/meta_extractor.py
Extracts meta tags, Open Graph data, and structured data from pages. Supports JSON-LD, Microdata, and RDFa formats. Generates comprehensive metadata reports for SEO analysis and content discovery.
