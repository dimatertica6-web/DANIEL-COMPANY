Visual

Dashboards, charts, live monitors, network graphs, and terminal UI.
dashboard
visual/dashboard.py
Web-based real-time dashboard showing attacks, bot status, and system metrics. Includes customizable widgets and dark mode. Implements live data streaming with WebSockets and auto-refresh capabilities with configurable intervals.
charts
visual/charts.py
Generates line, bar, and pie charts for attack statistics, bandwidth usage, and performance metrics. Uses matplotlib and plotly. Implements interactive charts with zoom, pan, and hover information capabilities.
terminal_ui
visual/terminal_ui.py
Rich terminal UI with tables, progress bars, and live updating status. Uses curses and rich library for interactive controls. Implements keyboard navigation, color themes, and real-time updates with support for terminal resizing.
network_graph
visual/network_graph.py
Generates interactive network graphs showing bot connections, attack paths, and data flows. Uses networkx and graphviz with force-directed layout. Supports node grouping, color coding, and dynamic filtering of connections.
