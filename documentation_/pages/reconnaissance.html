Reconnaissance

Passive & active reconnaissance, OSINT, fingerprinting.
port_scanner
reconnaissance/port_scanner.py
TCP and UDP port scanning with SYN, CONNECT, and FIN scans. Supports range and list modes, service detection via banner grabbing, and OS fingerprinting. Implements stealth scanning techniques with randomized delays and decoy packets.
subdomain_scanner
reconnaissance/subdomain_scanner.py
Brute-force and dictionary-based subdomain discovery with wildcard detection. Uses DNS resolution and can perform zone transfers. Supports concurrent queries and rate limiting. Includes wordlists for common subdomains and custom bruteforce patterns.
dns_scanner
reconnaissance/dns_scanner.py
Comprehensive DNS enumeration: A, AAAA, MX, NS, SOA, TXT, CNAME, and SPF records. Performs reverse DNS lookups and DNSSEC validation. Can detect DNS cache poisoning vulnerabilities and misconfigured resolvers.
whois_scanner
reconnaissance/whois_scanner.py
WHOIS lookup for domain registration, nameservers, creation/expiry dates, and registrant information. Caches results to avoid rate limits. Supports both IPv4 and IPv6 WHOIS servers with automatic fallback.
vulnerability_scanner
reconnaissance/vulnerability_scanner.py
CVE-based vulnerability scanner using a local database with over 100,000+ entries. Checks for known vulnerabilities in services, frameworks, and CMS versions. Generates detailed reports with CVSS scores and remediation steps.
technology_scanner
reconnaissance/technology_scanner.py
Fingerprint web technologies: server headers, JavaScript libraries, frameworks, CMS, and analytics. Uses a large signature database with pattern matching and machine learning classification for accurate identification of over 500 technologies.
