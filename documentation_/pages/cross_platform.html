Cross Platform

Platform detection and compatibility layers for Windows, Linux, macOS, Android, iOS.
platform_detector
cross_platform/platform_detector.py
Detects OS, kernel version, architecture, and distribution. Provides capabilities and feature flags based on platform. Implements runtime platform detection and feature availability checking with fallback mechanisms.
windows_platform
cross_platform/windows_platform.py
Windows-specific utilities: registry, service, WMI, and WinAPI bindings. Handles paths, permissions, and environment quirks. Implements Windows-specific process management, file operations, and system interaction.
linux_platform
cross_platform/linux_platform.py
Linux-specific: /proc, /sys, netlink, cgroups, and systemd. Implements POSIX compliance and glibc compatibility. Handles Linux-specific process management, file system operations, and system configuration.
macos_platform
cross_platform/macos_platform.py
macOS-specific utilities: launchd, plist management, and system preferences. Implements macOS-specific process handling, file system operations, and system event handling with security framework integration.
