API Scanner

REST, GraphQL, SOAP endpoint discovery and auth detection.
rest_scanner
api_scanner/rest_scanner.py
Discovers REST API endpoints by crawling and fuzzing. Detects authentication methods (JWT, OAuth, Basic), parameter injection points, and response analysis. Supports OpenAPI/Swagger specification parsing and validation.
graphql_scanner
api_scanner/graphql_scanner.py
Introspection-based GraphQL scanner. Retrieves schema, fields, types, and arguments. Detects vulnerable queries and depth limitations. Can perform batch queries and alias abuse testing.
auth_detector
api_scanner/auth_detector.py
Identifies authentication mechanisms by analyzing responses and headers. Tests for weak credentials, session hijacking, and misconfigured CORS. Implements JWT token analysis and rate limiting bypass detection.
