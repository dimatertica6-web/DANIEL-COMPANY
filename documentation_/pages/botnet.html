Botnet

Bot client, server, command distribution, encryption, status monitoring.
bot_manager
botnet/bot_manager.py
Central bot management: tracks online/offline bots, assigns tasks, collects results, and manages bot states. Provides a web-based dashboard for real-time monitoring. Supports bot grouping and filtering.
command_distributor
botnet/command_distributor.py
Distributes commands to bot clients with priority queuing and retry logic. Supports broadcast, targeted, and scheduled command execution. Implements command persistence and offline queue storage.
bot_encryption
botnet/bot_encryption.py
End-to-end encryption for bot communication using ECDH key exchange and AES-GCM. Prevents eavesdropping and man-in-the-middle attacks. Implements perfect forward secrecy and key rotation.
bot_client
botnet/bot_client.py
Bot client implementation that connects to C2, receives commands, and executes tasks. Implements auto-reconnect, heartbeat, and zombie prevention. Supports multiple communication protocols.
bot_status
botnet/bot_status.py
Bot status monitoring and reporting: uptime, connected peers, resource usage, and task completion status. Provides real-time updates and historical trends via WebSocket connections.
