Data Harvester

Credentials, cookies, tokens, emails, forms, API keys, source code extraction.
credential_harvester
data_harvester/credential_harvester.py
Extracts login credentials from forms, basic auth headers, and in-memory data. Captures both plaintext and hashed passwords. Supports automatic detection of login forms and credential fields using DOM analysis and pattern matching.
cookie_harvester
data_harvester/cookie_harvester.py
Steals session cookies, tokens, and other browser storage data. Decodes and parses JWT tokens, extracting claims and metadata. Supports harvesting from HTTP headers, browser storage, and network traffic interception.
api_key_harvester
data_harvester/api_key_harvester.py
Searches for API keys and secrets in source code, configuration files, and environment variables. Uses regex patterns for AWS, Google, Stripe, GitHub, and 50+ other services. Implements entropy-based detection for unknown key formats.
email_harvester
data_harvester/email_harvester.py
Extracts email addresses from HTML, text, and source code. Implements validation and deduplication of harvested addresses. Supports extraction from mailto links, plain text, and JavaScript variables.
source_code_harvester
data_harvester/source_code_harvester.py
Downloads and analyzes source code files from websites and repositories. Extracts comments, documentation, and sensitive data embedded in code. Supports automatic detection of code snippets and pastebin-style content.
