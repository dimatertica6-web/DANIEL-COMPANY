Encryption

AES, RSA, Fernet, XOR, Caesar, file encryption, and key management.
aes
encryption/aes.py
AES-256 encryption in GCM and CBC modes with IV generation. Supports key derivation from passwords and secure memory handling. Implements authenticated encryption with integrity verification and support for large file streaming.
rsa
encryption/rsa.py
RSA-2048/4096 encryption with OAEP padding. Supports private/public key generation, PEM serialization, and hybrid encryption for large payloads. Implements digital signatures and verification using RSA-PSS.
fernet
encryption/fernet.py
Fernet symmetric encryption (AES-128 in CBC) with HMAC authentication. Provides time-limited tokens and secure key management. Supports token expiration, rotation, and offline key storage.
file_encryptor
encryption/file_encryptor.py
Encrypts and decrypts files of any size using streaming encryption. Supports multiple encryption algorithms and compression before encryption. Implements chunked encryption for large files with progress reporting.
